# Thermography Analysis Dashboard

![Dashboard Banner](https://github.com/D-CHAUDHARYY/Thermography-PowerBI-/blob/main/Thermography%20Dashboard.png)

## Overview

This project focuses on thermography-based defect analysis of solar modules using Power BI and SQL. The dashboard helps identify module abnormalities, hotspot defects, temperature deviations, and maintenance priorities in a 100 MW solar power plant.

---

## Features

* Module defect identification
* Hotspot analysis
* Temperature deviation monitoring
* VOC & ISC comparison
* Defect category visualization
* KPI-based maintenance prioritization
* Interactive Power BI dashboard

---

## Technologies Used

* Power BI
* SQL
* MySQL
* Excel
* SCADA Data
